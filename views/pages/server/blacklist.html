Lista Negra

En este archivo se guardan los GUIDs de usuarios baneados. Si el modo de lista negra está en "2", los usuarios se van a agregar automáticamente a esta lista cuando sean expulsados. Podés editar esta lista manualmente sin importar el modo de lista negra, pero vas a tener que reiniciar el servidor para que los cambios manuales tengan efecto.
