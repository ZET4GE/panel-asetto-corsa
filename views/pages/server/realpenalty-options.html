Opciones de Real Penalty

Real Penalty es la popular app del lado del servidor diseñada para administrar penalizaciones personalizadas en carreras organizadas.

Real Penalty no es desarrollado ni mantenido por {{ if $.IsHosted }}Emperor Servers{{ else }}los autores de Server Manager{{ end }}. Si tenés preguntas sobre el funcionamiento de la herramienta Real Penalty en sí, por favor preguntá en el hilo de soporte de Real Penalty.

Real Penalty no está instalado. Seguí las instrucciones de abajo para instalarlo, o contactá a tu Administrador del Servidor:

  1. Descargar Real Penalty {{ $.RealPenaltySupportedVersion }}
  2. Extraé Real Penalty {{ $.RealPenaltySupportedVersion }}.zip
  3. Renombrá la carpeta extraída a realpenalty
  4. Movela dentro de tu carpeta assetto. Si usás multiserver, copiala dentro de cada uno. Por ejemplo, dentro de youracserver/servers/SERVER_00/assetto/
  5. Asegurate de haber configurado la Dirección del Plugin UDP y el Puerto Local del Plugin UDP en Opciones del Servidor
  6. ¡Actualizá esta página!

Nota: se sabe que estas instrucciones y la integración provista son compatibles con la versión {{ $.RealPenaltySupportedVersion }} de Real Penalty. Es posible que otras versiones también funcionen. Si tenés problemas con una versión más reciente que esta, por favor reportá un issue.
