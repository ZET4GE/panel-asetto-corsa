Importar Campeonato

Acá podés importar campeonatos en formato JSON (este formato coincide con el que se genera al exportar un campeonato). No recomendamos crear estos datos manualmente, ya que el formato es bastante complejo. Sin embargo, si querés mover campeonatos entre servidores pero no tenés acceso a los archivos, ¡podés usar esta función!
